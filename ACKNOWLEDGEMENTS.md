# Credits & Acknowledgements

SoundShade is built using native Swift and C++ APIs and leverages the following open-source resources:

* **m1ddc**: A command-line tool to control monitor brightness and volume using DDC/CI on Apple Silicon Macs.  [MIT license](https://github.com/waydabber/m1ddc#MIT-1-ov-file)
* **ProxyAudioDevice**: A lightweight CoreAudio HAL audio plug-in template used to bridge and route volume attenuation signals on macOS. ([Unlicense license](https://github.com/briankendall/proxy-audio-device?tab=Unlicense-1-ov-file#Unlicense-1-ov-file))
